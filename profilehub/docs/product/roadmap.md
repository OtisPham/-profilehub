# 🗺️ ProfileHub Product Roadmap

## 🚩 Sprint 1 — Core System Foundation (Hiện tại)
* [x] **Core Architecture & Documentation:** Đặc tả PRD, System Design, Data Schema, API Contract.
* [x] **Database & Migrations:** 8 bảng core trên PostgreSQL/Supabase kèm RLS policies.
* [x] **Backend Edge Functions:** CRUD Projects, Verification flow, Profile lookup, Jobs & Pipeline updates.
* [x] **Frontend Unified Layout & Skeletons:** MainLayout + Sidebar, giao diện Student, Teacher, Recruiter.

## 🚩 Sprint 2 — Career Discovery Agent & AI Assistance
* [ ] **Discovery Engine:** Chatbot định hướng nghề nghiệp, trích xuất dữ kiện tự động.
* [ ] **Live Career DNA Panel:** Tính điểm Employability Score và đồng bộ thời gian thực.
* [ ] **AI Smart Match:** Tự động so khớp JD và xếp hạng ứng viên theo bằng chứng.

## 🚩 Sprint 3 — Interview Coach & Knowledge Gap Analyzer
* [ ] **Mock Interview Simulator:** Sinh câu hỏi tình huống từ đồ án verified & JD.
* [ ] **Blind Spot Analysis:** Tự động tổng hợp lỗ hổng kiến thức từ feedback của nhà tuyển dụng.
