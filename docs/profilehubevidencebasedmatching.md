# Profile Hub — Evidence-Based Matching

## 01. Mục tiêu

Profile Hub hiện có 3 hệ thống tính năng chính:

1. AI Recruitment
2. Project / Portfolio
3. Lecturer Verification

Không cần tạo thêm một feature lớn mới.

Mục tiêu tiếp theo là:

> Kết nối 3 feature hiện có thành một trải nghiệm tuyển dụng dựa trên bằng chứng.

Core concept:

AI Recruitment
+
Verified Project
+
Evidence-based Matching

=

A recruitment experience where recruiters can understand WHY a candidate matches a job.
